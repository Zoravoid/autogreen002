# Mylinks-spring-boot

# Instructions for running the application

In src -> resources -> application.properties - modify the following properties, with the corresponding username and password for your mysql server:
```
spring.datasource.username=root
spring.datasource.password=free
``` 

Start the application using MyLinksSpringBootApplication class.


## Swagger
Swagger is an open source set of rules, specifications and tools for developing and describing RESTful APIs. The Swagger framework allows developers to create interactive, machine and human-readable API documentation.

Swagger is available on this url: http://localhost:8080/swagger-ui/
